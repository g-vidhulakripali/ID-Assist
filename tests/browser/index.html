ID Assist controlled test pages

Each page exists in two modes. Extension links are plain pages for testing the real extension loaded in Edge. Harness links add ?harness, which injects a fake chrome runtime and the built content script so the UI can be exercised without installing anything (run npm run build:harness first).

In harness mode the fake tab registry persists in sessionStorage; call idAssistHarness.resetTab() in the console to simulate a fresh tab.
